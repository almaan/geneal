How to read this

Setup. Efficacy (lethality in the target line) AND toxicity are both unknown and explored jointly by an active-learning loop using EHVI (Expected Hypervolume Improvement) over the (efficacy↑, toxicity↓) objective space.
Toxicity reference — contrast: lethality in a fixed proxy cell line (different-domain stand-in for normal tissue); population: mean lethality across all lines.
Hypervolume regimes — learned: toxicity predicted + explored; known: toxicity oracle (a-priori), only efficacy learned; oracle: full information (both known) = absolute ceiling.
Final nomination — from the learned bivariate surrogates we nominate K targets, as a ladder: efficacy_only (top-K by predicted lethality, ignoring toxicity) → joint (top-K by predicted selectivity = efficacy − toxicity; pathways unrestricted — any pathways) → joint_cap2 (joint, but ≤2 genes per pathway — the portfolio hedge). Metrics below are TRUE values of the nominated set. concentration = max fraction in one pathway (↓ better); robustness = expected value surviving a random pathway dropout (↑ better).
